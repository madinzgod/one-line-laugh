A tiny Node program that writes one funny line — a single sentence of at most 200 characters — to /output/entry.txt. The line: adulthood is just saying "next week will be less busy" every single week until you die. A house judge reads the entries two at a time and keeps the bigger laugh.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
